Engineer Profile

Background & Philosophy

I am Mark — an AI Engineer based in Ukraine. I design and ship LLM-powered systems that run in production: multi-agent pipelines, generative media engines, data tooling and automation bots.

I'm self-taught and project-driven: tool-using agents, prompt and context engineering, agent evaluation, Python automation, computer vision, procedural 3D in Blender and a native Rust + Tauri desktop app. I treat an AI product not as a single prompt, but as a system of agents, tools, memory and feedback loops that has to work reliably every day.

“I build AI systems that don't just demo well — they run 24/7, check their own output and ship real results.”
  • 01

  • 02

    QA agents and checklists catch defects before output ships, so humans review results, not fix them.
